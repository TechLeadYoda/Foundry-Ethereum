- retenir la licence : Software Package Data Exchange License Identifier: MIT
*MIT	Anyone can use, copy, modify and sell it, as long as they keep your copyright notice. The most common choice.
*UNLICENSED	No permission given: all rights reserved. Others may read the code but not reuse it.
*Unlicense	The opposite: public domain, anyone can do anything, no conditions.
*GPL-3.0	Free to use and modify, but any project that includes it must also publish its code under GPL.
*AGPL-3.0	Same as GPL, and it also applies when the code runs as an online service.
*BUSL-1.1	Source is visible, but commercial use is forbidden for a few years, then it becomes open. Uniswap v3 used it to stop competitors copying it at launch.

-function return type and so one 
function name(parameters) visibility mutability returns (types) { }
Mutability is the optional word in the middle:
nothing → the function can change state (like increment)
view → reads state, changes nothing
pure → neither reads nor changes state
payable → can receive ETH

- 3 parts of foundry : forge(deploy, build ...), anvil( local blockchain), cast(to call the blockchain)
- to deploy: 
    forge create src/Counter.sol:Counter   
    --rpc-url http://127.0.0.1:8545   
    --private-key <Private_key>   --broadcast
    1- safer encrypted the private key : cast wallet import testKey --interactive
    2-verify if it s done: cast wallet list
    3-to deploy : forge create src/Counter.sol:Counter \
    --rpc-url http://127.0.0.1:8545 \
    --account testKey \
    --broadcast
- retenir command :
    cast   wallet   import   key4   --interactive
    outil  groupe   action   nom    comment

    forge create → déployer un contrat
    QUOI ? src/Counter.sol:Counter → le fichier, deux-points, le nom du contrat
    OÙ ? --rpc-url http://127.0.0.1:8545 → sur quelle blockchain (anvil, port 8545)
    QUI ? --account key4 → qui signe et paie
    POUR DE VRAI ? --broadcast → envoyer vraiment ; sans lui, c’est une simulation

    La loi : OUTIL → ACTION → QUOI → OÙ → QUI

    Toutes les commandes Foundry se construisent dans cet ordre :

        OUTIL	ACTION	QUOI	OÙ	QUI
    Ajouter une clé	cast	wallet import	key4	—	--interactive
    Déployer	forge	create	src/Counter.sol:Counter	--rpc-url ...	--account key4
    Écrire	cast	send	<ADRESSE> "increment()"	--rpc-url ...	--account key4
    Lire	cast	call	<ADRESSE> "number()(uint256)"	--rpc-url ...

1-interract with a contract
   call = read, send = write (needs --account)
   Pattern is always: cast <verb> <address> "<signature>" <args>
   example : cast call <ADDRESS> "number()(uint8)" --rpc-url http://127.0.0.1:8545

2-accessibility
    public → everyone (outside + inside)
    external → outside only (functions only)
    internal → contract + children
    private → contract only (still readable on chain)

    Functions vs variables

    Function → 4 options, visibility mandatory
    Variable → 3 options (no external), default internal
    public variable → auto getter number()
